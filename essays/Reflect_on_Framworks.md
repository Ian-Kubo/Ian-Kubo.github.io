## 
One of the first observations I noticed when using Boostrap 5 compared to using plain HTML and CSS was just how much more beautiful the pages I was creating looked. A crucial skill of working in front-end development is the ability to create not only functional webpages but also good looking and aesthetically pleasing ones. And while CSS may aid in the process, Bootstrap 5 makes that process more efficient. Although it was difficult to navigate all of Bootstrap's features in one week, I couldn't deny the good results it has produced for me so far. Getting a feel of how Bootstrap aids in website creation was a fun challenge with rewarding results. I hope to continue to learn more about UI frameworks throughout my schooling and career. 

## Working out the Quirks

When beginning with Bootstrap, it was apparent that I had trouble understanding the logic of formatting the Bootstrap layout. From container classes to nav bar components, I felt as though everything was thrown at me all at once. I had a difficult time understanding Bootstrap's way of webpage content wrapping, and it felt overwhelming with all the nested div tags. However, after watching several tutorials on Bootstrap logic and practicing making simple navbars and basic webpages, all of it started to finally click. On top of  layout, dealing with the multitude of class modifiers and properties also felt quite overwhelming as a beginner. Futhermore, the syntax of adding these properties to classes was quite relaxed as they are only distiguished with spaces and not with commas like a parameter. It was frustrating to see this type of simplicity even though Python is my primary coding language. 

## What I Enjoyed

Eventually, after getting over what I thought was a steep learning curve, I could finally see just how powerful Bootstrap is for the developer. One thing that stood out to me was the intuitive grid layout system that can be modified for different screen lengths. Putting simple scaling properties in the class tag such as ``<div class="col-sm-4 col-lg-6"> `` made it simple to adjust the columns as the website screen resized. I thought it was a well made feature that makes a developer's life a little easier. Using just raw HTML and CSS would take you pretty far, but it would not be as intuitive without the help of Bootstrap. I think the most challenging part about using this framework is reading the documentation to know exactly what features you want for a webpage. Therefore, it is necessary to keep practicing and learning. 

## My project using Bootstrap

For my Your Choice Project, I tried to recreate the Houston Rocket's home webpage using Bootstrap 5. What stood out to me about this webpage was the vibrant colors and stacked navigation bars. The webpage consisted of two navigation bars and two footers, which I thought was good for practicing. The first navbar also had two dropdown menus, and when the screen was resized, it converted each navigation link into one big dropdown menu. For the footers, they contained several columns with many links. For simplicity, the main content consisted of a game day tracker that contained individual game day frames and arrows to create a carousel. Below that contained another carousel with several created media posts. What I took away from this project was the efficiency in creating several different features within my website. It was a rather smooth process from developing the basic layout to styling using CSS. However, one problem I ran into with using Bootstrap 5 was implementing Javascript for the dropdown menus. I saw that I could click and open a drop down, but I could never retract the menu back. I eventually needed AI assistance to help with the problem, and it pointed out that I had to add a specific Javascript script to make the dropdown work properly. This showed again that I have much to learn. Overall, the project was a success and you can check it out in the picture above!

## Conclusions

The bottom line: UI frameworks have an exhaustive amount of content and features that makes webpages beautiful and useful. It takes time learning how to create and wrap certain pieces of content, but the return on investment of learning this skill makes you a more valuable candidate for a possible job and could skyrocket your career. Bootstrap 5 is one of many frameworks you can work with, and my personal experience with it is currently a positive one. It motivates me to go out and create more projects for myself and others!
