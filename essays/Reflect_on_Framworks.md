One of the first things i noticed when using boostrap compared to just using plain html and css was just how much more beautiful the pages looked. A large part of diving into front-end development is how to create a good-looking webpage. And bootstrap does just that. Although it is difficult to navigate all of bootstrap's features, you can't deny the good results it produces. Getting a feel of how bootstrap creates these websites is both a fun challenge and rewarding. I hope to continute to learn more about UI frameworks throughout my career. 

## The Basics: 

When beginning with bootstrap, it was apparent that I had trouble with the logic of formatting the bootstrap code. From container classes to nav bars, I felt as though everything was thrown at me all at one time. It did not make intuitive sense on the wrapping of webpage content. It felt overwhelming with all the nested div tags. However, after watching several tutorials on bootstrag logic and practicing making simple navbars and basic webpages, all of it started to finally click. On top of the formatting, the multitude of class modifiers and properties can also feel quite overwhemling as a beginner. Also the syntax of adding these properties to these classes is quite relaxed as they are only separated by spaces and not commas like a parameter. It was quite fustrating to see this as a person who enjoys C and Java, where syntax is heavily emphasied.  

## What I enjoyed:

Eventually, after getting over the strong learning curve, I could finally see just how powerful bootstrap was for the software engineer. One thing that stood out to me was the easy and intuitive grid layout system that can be modified for different screen lengths. Putting simple scale properties in the class such as ---- made it simple to adjust the columns as the website screen resized. I thought it was such a well made feature that makes its easy to create a webpage the way you want. Using raw html and CSS would take you pretty far, but it would not be as intuitive without the help of bootestrap. I think the most challenging part about using it is reading the documentation to know exactly what features you wnat for the webpage. Therefore, it is necessary to keep practicing and learning. 

## My project using UI frameowrks

More specifically, for my your choice project, I tried to recreate the Houston rocket's home webpage using bootstrap 5. The webpage consisted of two navbars and two footers, which was good for learning by doing. The first navbar also had two dropdowns and when the screen was resized, it converted the navigation links into dropdown menus. Fpr the footers, it contained several columns with many links. For the main content, I had a game-day tracker that contained arrows within a mobil menu item. What I took away from this project was the efficiency I could create several different features within my website. It was a pretty smooth process when creating the whole thing and styling using CSS. However, one problem I ran into with using bootstrap 5 was the javascript implementation for dropdown buttons. I saw that I could click and open the drop down, but could never retract it back. I eventually had to use AI to help with the problem, and it showed that I had to implement a javascript script to make create the feature. This showed that again I have much to learn. Overall, the project was a success and you can check it out from the picture above!

## Conculsisons

The bottom line: UI frameworks have an exhaustive amount of content and features that makes webpages beautiful and useful. It takes time learning how to create and wrap certain pieces of content, but the ROI of learning this skill makes you a more valuable candidate for a job or could open more doors in terms of your career. Bootstrap 5 is one of many frameworks you can work with, and my personal experience with it currently is a positive one. It motivates me to go out and create more projects for myself and others.
