## Project: UHM Accessibility Rating Map 

## Overview
<strong>Problem:</strong> Accessibility features like elevators, wheelchair ramps, and accessible parking spaces are important parts of making the UH campuses accessible to everyone. However, not all of these features are well known across the campus nor are they of the same quality. 
<strong>Solution:</strong> Creating a rating map allows students to collectively bring attention to what works well on campus for people but also bring attention to what needs to be improved on campus.

## Mockup Page Ideas

<ul>
  <li><strong>Landing page:</strong> Description of the website and allows user to filter by elevators, ramps, parking etc.</li>
  <li><strong>User home page:</strong>Displays the different accessibility features, allows for ratings and comments on each location. Users have the option of adding a new feature.</li>
  <li><strong>Admin home page:</strong> Allows admins to see posted accessibility features and review add requests and comments.</li>
  <li><strong>Map page:</strong> Shows the location of features</li>
  <li>
    <strong>User profile page:</strong> Lets user update their personal information</li>
</ul>

## Use Case Ideas 

New users are able to view the site and map but not make any ratings or requests.
User logs into UH account to get permission to rate existing locations/features or request new ones to be added
Administrator users can accept or deny the requests, edit site, etc.
